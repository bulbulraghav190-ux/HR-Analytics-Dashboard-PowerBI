# HR Analytics Dashboard 📊

This is my **HR Analytics Dashboard** project created using **Power BI**.

The main goal of this project is to explore employee data and understand **employee attrition** using different HR-related factors such as department, salary, age, gender, job role, job satisfaction, and experience.

## 📌 Project Overview

The dataset contains information about employees, including their:

* Age and Age Group
* Department
* Gender
* Job Role
* Job Satisfaction
* Salary Slab
* Attrition
* Total Experience
* Business Travel
* Overtime
* Education
* Monthly Income
* Years at Company

The dataset contains **1,480 employee records and 37 columns**.

## 📊 Dashboard KPIs

Some important numbers shown in the dashboard are:

* **Total Employees:** 1.417K
* **Active Employees:** 1.186K
* **Attrition Count:** 231
* **Attrition Rate:** 16.30%
* **Average Age:** 36.94
* **Average Experience:** 7.04 years

## 📈 Dashboard Analysis

The dashboard includes:

* Attrition by Department
* Employee Count by Salary Slab
* Attrition by Job Role and Job Satisfaction
* Age Group Distribution
* Attrition by Gender
* Attrition Trend by Experience
* Employee Count by Department
* Age Group Filter
* Department Filter
